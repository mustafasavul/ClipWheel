# Security Policy

ClipWheel stores clipboard data locally and intentionally avoids telemetry, analytics, cloud sync, and external OCR services.

## Reporting A Vulnerability

Open a private security advisory or email the maintainer with reproduction steps, affected versions, and any relevant logs. Do not include real secrets or private clipboard data in reports.

## Sensitive Data

ClipWheel can skip or mask likely sensitive content. Detection is best-effort and should not be treated as a data-loss-prevention guarantee.
