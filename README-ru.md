# ClipWheel — Уникальный радиальный менеджер буфера обмена

**Хватит прокручивать списки истории буфера обмена. Откройте для себя самый быстрый способ доступа к вашему буферу обмена с помощью кругового меню. Нажмите одно сочетание клавиш, смахните к нужному сегменту и вставьте.**

ClipWheel — это бесплатный, открытый и ориентированный на конфиденциальность менеджер буфера обмена для **macOS, Windows и Linux**, который представляет собой потрясающее радиальное колесо (также известное как круговое меню, marking menu или hotbox), позволяющее держать ваши последние 4–12 скопированных элементов на расстоянии одного жеста, при этом никакие данные никогда не покидают ваше устройство.

## 🎡 Почему колесо, а не еще один список?

Любой другой менеджер буфера обмена предлагает вам **вертикальный список**: открыть окно, прочитать сверху вниз, найти нужную строку, кликнуть. Это задача *поиска* — ваши глаза выполняют работу каждый раз.

ClipWheel превращает это в задачу **мышечной памяти**.

- **Фиксированные позиции.** Ваши последние N копий каждый раз находятся в одних и тех же сегментах. "Предпоследняя" копия всегда находится в одном и том же направлении — в правом верхнем углу, а не "где-то в районе второй строки".
- **Радиальный значит равноудаленный.** В списке 8-й элемент находится на восемь строк дальше, чем 1-й. На колесе каждый сегмент находится на одинаковом расстоянии смахивания.
- **Один жест, без чтения.** Откройте колесо, двигайтесь к сегменту, выберите. Или нажмите `1`–`8`. Колесо закрывается, и элемент снова в вашем буфере обмена.
- **Предварительный просмотр (Quicklook).** Удерживайте `Shift` для **Быстрого просмотра** — полного предварительного просмотра текста, кода или изображения в этом сегменте, не покидая колеса.
- **Размер под вашу память, а не архив.** От 4 до 12 сегментов на ваш выбор. Колесо обрабатывает последние несколько скопированных вами элементов — это 90% случаев, менее чем за секунду. Окно истории берет на себя остальные 10% благодаря поиску, фильтрам и предварительному просмотру.

### История и Поиск
- Полноценное окно истории с **поиском, фильтрами по типам, фильтрами по дате и пагинацией**.
- **Многофункциональная панель просмотра** для текста, кода, форматированного текста, URL, изображений и ссылок на файлы.
- **Метаданные для каждого элемента**: размер в байтах, читаемый размер, длина текста, количество строк, количество файлов, время создания и последнего использования.
- **Закрепление, добавление в избранное и преобразование текста** для любой записи.
- **Корзина с мягким удалением**, восстановлением и явной безвозвратной очисткой.

### Захват
- Обычный текст · форматированный текст / HTML / RTF · изображения и скриншоты · ссылки на файлы и папки · URL · фрагменты кода с определением языка · команды терминала.
- Локальное хранилище ресурсов изображений с генерируемыми миниатюрами.
- Переключатели захвата для каждого типа и обработка дубликатов.

### Конфиденциальность и Контроль
- **Пауза захвата**, **игнорируемые приложения-источники** и **очистка при выходе**.
- Системная / темная / светлая тема, по умолчанию следует настройкам ОС.
- Встроено **24 языка**, включая языки с письмом справа налево (арабский, персидский).
- Иконка в трее, автозагрузка и подписанные обновления на месте (in-place) из GitHub Releases.

## 🔒 Модель Конфиденциальности

ClipWheel **создан с приоритетом локального хранения по дизайну, а не по обещаниям**:

- Всё хранится в локальной базе данных **SQLite** и папке с ресурсами изображений внутри директории данных приложения Tauri.
- **Никакой телеметрии. Никакой аналитики. Никаких аккаунтов. Никакой облачной синхронизации. Никаких внешних сервисов.**
- Единственный сетевой запрос, который делает приложение — это проверка обновлений по публичному URL метаданных GitHub Releases.
- Содержимое буфера обмена хранится точно в том виде, в котором оно было скопировано — без облачных классификаторов, без OCR, без маскирующего слоя, отправляющего что-либо за пределы устройства.

В вашем буфере обмена часто находятся самые чувствительные данные: пароли, токены, личные сообщения. Вот почему они никогда не покидают устройство.

## 📦 Установка и Быстрый старт

### macOS

```bash
brew install --cask mustafasavul/tap/clipwheel
```

Или скачайте `.dmg` для вашего процессора из [последнего релиза](https://github.com/mustafasavul/ClipWheel/releases/latest): `ClipWheel_0.2.0_aarch64.dmg` (Apple Silicon) или `ClipWheel_0.2.0_x64.dmg` (Intel).

### Windows

Скачайте и запустите из [последнего релиза](https://github.com/mustafasavul/ClipWheel/releases/latest): `ClipWheel_0.2.0_x64-setup.exe` (установщик NSIS) или `ClipWheel_0.2.0_x64_en-US.msi`.

### Linux

```bash
sudo apt install ./ClipWheel_0.2.0_amd64.deb
```

```bash
chmod +x ClipWheel_0.2.0_amd64.AppImage && ./ClipWheel_0.2.0_amd64.AppImage
```

> Ранние версии могут быть неподписанными или иметь временную подпись. macOS Gatekeeper и Windows SmartScreen могут выдавать предупреждения до тех пор, пока не будут настроены нотаризация Apple и доверенная подпись Windows.

### Первые 30 секунд

1. Запустите ClipWheel — он живет в вашем системном трее / строке меню.
2. Скопируйте несколько элементов.
3. Нажмите **`Cmd+Shift+V`** (macOS) или **`Ctrl+Shift+V`** (Windows/Linux).
4. Переместитесь в сторону сегмента или нажмите `1`–`8`. Удерживайте `Shift` для предварительного просмотра.
5. Вставьте.

| Действие | Сочетание клавиш |
| --- | --- |
| Открыть колесо | `Cmd+Shift+V` / `Ctrl+Shift+V` |
| Выбрать элемент | `1`–`8` или `Enter` |
| Быстрый просмотр (Quicklook) | Удерживать `Shift` |
| Закрыть колесо | `Esc` |

## 🛠 Разработка

```bash
pnpm install
pnpm dev
```

Проверка перед открытием Pull Request (PR):

```bash
pnpm lint && pnpm typecheck && pnpm version:check && pnpm test
```

Сборка установщиков:

```bash
pnpm tauri build
```

Для сборки релизов требуется `TAURI_SIGNING_PRIVATE_KEY` (и дополнительно `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`). CI smoke packaging использует `pnpm package:ci`, поэтому pull-реквесты собираются без секретов подписи релиза.

### Структура проекта

| Путь | Назначение |
| --- | --- |
| `src-tauri/src` | API ОС, буфер обмена, трей, шорткаты, SQLite, очистка, команды Tauri |
| `src/shared` | Чистые доменные типы TypeScript, константы, пакеты i18n, утилиты |
| `src/renderer/api` | Типизированная граница команд/событий Tauri (`clipwheelClient.ts`) |
| `src/renderer/data` | Хуки React Query, инвалидация кэша, подключение провайдера API |
| `src/renderer/features` | Поверхности функций: `wheel`, `history`, `preview`, `settings` |
| `src/renderer/presentation` | Помощники по форматированию и отображению |
| `src/renderer/ui` | Переиспользуемые примитивы UI |
| `src/renderer/styles` | Семантические токены, CSS макетов и функций |

Правила архитектуры для контрибьюторов и кодирующих агентов: [AGENTS.md](AGENTS.md). Рабочий процесс: [CONTRIBUTING.md](CONTRIBUTING.md). Документация по релизам и версиям: [docs/](docs).

## ⚠️ Известные ограничения

- Автоматическая вставка (Auto paste) существует как настройка, но отключена и пока не симулируется.
- Ссылки на файлы пока восстанавливаются как текстовые пути.
- Определение исходного приложения является заполнителем (placeholder) — кросс-платформенные API активных приложений различаются.
- Установки, в которых уже была выбрана `тёмная` или `светлая` тема, сохранят этот выбор; для новых установок по умолчанию используется `системная`.
